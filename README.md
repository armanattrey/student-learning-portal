# Student Learning Portal

**Repository:** [https://github.com/armanattrey/student-learning-portal](https://github.com/armanattrey/student-learning-portal)

## Introduction

The Student Learning Portal is a beginner-friendly project that helps students set up a consistent environment for learning programming and practicing data structures and algorithms.

## About the Project

This project provides a one-click setup for C++ and DSA practice on Windows and macOS. It configures helpful development tools so students can focus on learning.

**Purpose:** Help students get started with coding practice using a ready-to-use development environment.

**Author:** Nishant (project creator); README prepared by Arman Sharma.

## Features

- One-click setup for Windows and macOS
- VS Code configuration with C++ and competitive-programming extensions
- C++ compiler setup for DSA practice
- Code snippets for common programming templates
- Backup and restore support for existing settings

## Technologies Used

1. C++ — programming language for DSA practice
2. PowerShell and shell scripts — setup automation
3. Visual Studio Code — code editor
4. Markdown — project documentation
